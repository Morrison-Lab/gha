# Idioms, cliches and slang that check-quarto-prose flags in prose.
#
# The house style is plain, literal prose that a reader with English as a
# second language, or a literal reading style, can take at face value.
# See https://github.com/Morrison-Lab/psw for the prose rules themselves.
#
# Format
#   One phrase per line. Blank lines and lines starting with # are skipped,
#   and so is anything after a space followed by #.
#   Matching is case-insensitive and whole-phrase: "ballpark" does not match
#   "ballparkx". A space or a hyphen in a phrase matches a space, a hyphen,
#   or a line break (but never a blank line), so "hand-wavy" also finds
#   "hand wavy".
#   A word ending in * also matches the rest of that word. Use it only
#   where every continuation of the stem is the same idiom. Most stems are
#   not like that: "dive" or "pan" would match "diverges" and "panels", and
#   "chang*" would match "game changes". So every entry here lists its
#   inflections one per line, and none uses the star.
#
# A phrase list cannot see context. Some entries have a literal use or are
# fair to quote. Exempt one with <!-- prose-allow: phrase --> on the line, or
# list it in an allow-file.
#
# Why bare "lean" is not listed: it is an ordinary word (lean statistics,
# lean on a library). Only the figurative forms are.
