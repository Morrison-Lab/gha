# Product Definition: Reusable GitHub Actions for Morrison-Lab (gha)

## Vision

A centralized repository of reusable GitHub Actions workflows and composite actions serving d-morrison, UCD-SERG, and ucdavis organizations.
It focuses on maintaining CI/CD consistency, code quality, and security checks across R-package and Quarto repositories, allowing consumer repositories to call workflows via small stubs.

## Key Goals

- **Consistency**: Ensure all R-packages and Quarto repositories follow the same CI/CD standards.
- **Reusability**: Provide easily consumable workflow stubs to reduce boilerplate.
- **Security & Quality**: Enforce linting, PHI scanning, secret scanning, and automated testing across all projects.

## Target Audience

- Developers and researchers within Morrison-Lab, UCD-SERG, and affiliated organizations building R packages and Quarto websites.
