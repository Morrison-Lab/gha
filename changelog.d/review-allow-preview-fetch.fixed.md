- **`claude-code-review` can now fetch the rendered output its `prompt-addendum` tells it to check** (#199 follow-up). A repo whose addendum asks the reviewer to verify computed values/figures against the PR-preview site had no fetch tool granted, so each of the plugin's 4 parallel sub-agents racked up a permission denial per fetch attempt and the run finished without a verdict (36 denials on `rme#954`). `WebFetch` and `Bash(curl:*)` are now allowlisted, and the reviewer's system prompt is updated in lockstep to say the fetch tools are available (previously it told the agent no fetch tools existed, which would have defeated the grant). Neither tool adds exfiltration capability beyond the already-granted `Bash(python3:*)`, which can already make arbitrary requests via `urllib` (`WebFetch` is GET-only; `curl` can issue any verb).
