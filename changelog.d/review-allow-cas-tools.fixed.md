- **`claude-code-review` now lets the reviewer run the computer-algebra tools it installs** (#199). The `apt-packages` / `pip-packages` inputs install Maxima and SymPy for symbolically checking derivations, but the tool policy blocked `Bash(maxima:*)` and `Bash(python3 -c:*)`, so a math-heavy review (e.g. one whose `prompt-addendum` asks for CAS verification) burned permission denials and never emitted a verdict — failing `require-review`. `Bash(maxima:*)` is now allowlisted and `python3 -c` is no longer disallowed (inline SymPy); `python3 -m` and all git-write tools stay blocked.
