- `check-geometric-figures` also flags a definition of a geometric term
  (a curve, plane, distance, margin, boundary, region, and so on, in its title or bold term)
  whose next example has no figure,
  when a pull request touches the definition or that example (Ezra, 2026-11-22).
  The next example is found through `include` shortcodes,
  in the definition's file or after its include in a parent page.
  An example's own `no-figure` marker does not excuse it;
  `<!-- no-figure: reason -->` inside the definition does.
