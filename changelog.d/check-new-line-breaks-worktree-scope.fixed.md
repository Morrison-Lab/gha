- **`check-new-line-breaks` examines uncommitted lines when the tree is dirty, and reports its search space** (#825, #826). The script scoped its diff to `<base>...HEAD`, so a run before committing reported clean about lines it never read. A new `NLB_SCOPE` knob (`auto`, the default, or `worktree` or `committed`) scopes from the merge base against the working tree whenever tracked files the globs match carry staged or unstaged changes, keeps the committed-only scope on a clean tree, warns by name about untracked files it cannot see, and prints `Examined N added line(s) across M file(s) (scope: ...)` before the verdict.
