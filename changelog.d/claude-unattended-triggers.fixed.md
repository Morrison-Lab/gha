- **`claude.yml`'s job `if:` now allows `workflow_dispatch`/`schedule` events through** (#245). Previously the job's trusted-author gate only matched the four reactive, mention-triggered events (`issue_comment`, `pull_request_review_comment`, `pull_request_review`, `issues`), so a caller wired up for unattended/periodic invocation (e.g. a scheduled skill run) got a workflow that looked correctly configured but silently skipped the `claude` job on every run. The gate now also passes `workflow_dispatch`/`schedule` unconditionally — both require repo write access to trigger in the first place, so no comment-body/author-association check is needed. The agent's own prompt, and `examples/claude.yml`, were updated to explain that these unattended runs get no triggering issue/PR (no branch, draft PR, or reply comment), so the actual task belongs in `prompt-addendum` and any output must be persisted with tools `claude-args` grants.
